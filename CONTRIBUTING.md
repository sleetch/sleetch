Please observe the contribution guidelines below to ensure consistency and overall code quality across the project, so that every contributor can work on a well-maintained codebase.

We accept contributions aimed at fixing existing bugs, improving documentation, or implementing new features that we deem useful to everyone.

We will not accept contributions that involve a major rewrite of part of the project, contributions with content entirely generated by AI, or as previously mentioned contributions that solve only a personal issue.

Also, do not submit contributions to fix grammar or syntax errors, correct types, remove comments, remove `console.log(...)` statements, or modify the project's folder structure.

If you have an opinion on this, open an issue instead.

Since the codebase is primarily written in TypeScript, you will need to install the Biome extension in your editor; it handles formatting and reports code quality issues that you must address.

We don't have specific rules regarding commit naming or pull request content ; use your common sense and ensure everything is understandable to everyone in English.

If your contribution meets all these requirements, it will be reviewed but please understand that we may ask for additional changes before accepting the modifications.

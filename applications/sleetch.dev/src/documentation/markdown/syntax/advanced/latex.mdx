# Maths

(Sometimes) I like maths so this feature is here to write nicely formatted equations with LaTeX !

### Enable it

First enable this advanced markdown syntax in your configuration.

```ts title="my-project/sleetch.config.ts"
import type { sleetch_configuration } from '@sleetch/server';

export default {
  // ...
  markdown: {
    engine: 'marked', // Can be any engine
    plugins: {
      latex: true,
      // ...
    },
  },
} satisfies sleetch_configuration;
```

## Example

```text title='Katex Example'
Euler’s identity $e^{i\pi}+1=0$ is a beautiful formula in $\mathbb{R}^2$.
$$
\frac {\partial^r} {\partial \omega^r} \left(\frac {y^{\omega}} {\omega}\right)
= \left(\frac {y^{\omega}} {\omega}\right) \left\{(\log y)^r + \sum_{i=1}^r \frac {(-1)^ Ir \cdots (r-i+1) (\log y)^{ri}} {\omega^i} \right\}
$$
```

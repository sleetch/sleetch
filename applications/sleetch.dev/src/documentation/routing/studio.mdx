# A studio ?!

Are you managing a complex documentation based on Sleetch ? Don't start rolling around on the ground and panicking. Just launch the **studio** with a single command to learn more about the project sources, languages, pages, and how they all relate to one another.

![So much documentation](https://media.makeameme.org/created/so-much-documentation.jpg)

## Try it yourself

Check it out ! follow the steps below or on https://studio.sleetch.dev

- Open a terminal in your favorite sleetch project.
- Run the command ;
  ```bash
  bunx sleetch@latest studio
  ```
- Open the Studio link that appears in the console.

BTW, the sutdio is updated in realtime, go ahead and edit your pages, your configuration and you'll see that every changes are reflected in realtime in the sleetch studio.
